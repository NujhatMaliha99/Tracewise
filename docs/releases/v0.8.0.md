# Tracewise v0.8.0

Local-first API observability, reliability analysis and recoverable workspace operations.

Pre-release / local portfolio evaluation. Verification: 258 Python tests and 4 Node SDK tests passed.

## Included

- Four-service real HTTP fault experiments, request waterfalls and configured dependency candidates.
- Standard OTLP/HTTP JSON/protobuf traces, opt-in durable evidence, service ownership/environment catalog.
- Incremental live incidents, timelines and version-checked whole-request merge/split.
- Sampled availability/latency objectives, observed error budgets and 1h/6h burn watches.
- Change context, before/after descriptive comparison and explicit insufficient-evidence states.
- Draft evidence-indexed incident reviews, Markdown/JSON exports and accountable follow-ups.
- Admin workspace snapshots and offline non-overwriting restore with quarantined automation.
- Bounded token buckets, 429 Retry-After, OTLP error encoding and a concurrent connection cap.
- Existing role-based sessions, egress allowlists and SMTP/webhook outbox remain supported.

## Important Boundaries

Not a production-certified monitoring service, verified root-cause engine or autonomous repair tool.
SLOs use retained samples, not a complete traffic census. Change association is not causation.
Backups are private and unencrypted; restore only trusted same-version archives. Recovery disables
monitors, collection and pending notification replay. No public deployment is included in this release.
